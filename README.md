# OneSpeed — نسخه‌ی کاتلین (موتور واقعی Xray)

## این پروژه چیه؟

- **موتور اتصال** (`app/src/main/java/com/v2ray/ang/...` — پوشه‌های core/service/fmt/handler/dto/enums/util/contracts/root/helper) عیناً از یه فورک باثبات و در حال کار v2rayNG (پروژه‌ی dicodePing) کپی شده. اینا رو دست نزنید — این همون بخشیه که واقعاً وصل میشه، هر پروتکلی (vless/vmess/trojan/shadowsocks/reality/xhttp) رو می‌فهمه.
- **UI و منطق OneSpeed** (`app/src/main/java/ir/onespeed/app/...`) کاملاً تازه نوشته شده، دقیقاً با طراحی/جریانی که قبلاً تست کردیم: اسپلش → لاگین با توکن → داشبورد (دکمه اتصال، پلن، انتخاب لوکیشن با پینگ دستی کنار دکمه بستن).
- هسته‌ی واقعی Xray (`libv2ray.aar`) موقع build از یه ریلیز pinned (`patterniha/AndroidLibXrayLite v26.8.19-P`) دانلود میشه — دقیقاً همون نسخه‌ای که پروژه‌ی منبع استفاده می‌کنه.

## صادقانه بگم

این یکپارچه‌سازی بزرگیه — یه اپ واقعی و پیچیده رو گرفتیم، موتورش رو نگه داشتیم، UI روش عوض کردیم. برخلاف تلاش قبلی (فلاتر)، ریسک «اصلاً وصل نمیشه» خیلی پایین‌تره چون موتور دست‌نخورده و اثبات‌شده‌ست. ولی احتمال داره build اول یکی دو تا خطای کامپایل کوچیک بده (مثلاً یه import یا امضای تابع که کمی جابه‌جا شده) — **دقیقاً مثل هر مرحله‌ی قبلی، کل پیام خطا رو کپی کنید بفرستید، سریع درستش می‌کنم.**

یه محدودیت شناخته‌شده در این نسخه: نمایش لحظه‌ای سرعت آپلود/دانلود روی داشبورد هنوز وصل نیست (چون سرویس VPN توی یه پروسه‌ی جدا اجرا میشه و انتقال آمار ترافیک بین پروسه‌ای نیاز به یه مرحله‌ی اضافه داره) — اتصال/قطع/پینگ واقعیه، سرعت زنده رو بعداً اضافه می‌کنیم.

## چطوری با گیت‌هاب خروجی بگیرم

دقیقاً همون روندی که قبلاً گفتم، این‌بار برای این ریپو:

1. یه ریپوی گیت‌هاب جدید بسازید (یا همین یکی رو نگه دارید و محتواش رو عوض کنید)
2. توی Termux:
   ```
   cd ~
   unzip ~/storage/downloads/onespeed-kotlin-project.zip
   cd onespeed_kotlin
   git init
   git add .
   git commit -m "OneSpeed Kotlin — real Xray engine"
   git branch -M main
   git remote add origin https://github.com/USERNAME/onespeed.git
   git push -u origin main --force
   ```
   (اگه همون ریپوی قبلی فلاتر رو استفاده می‌کنید، `--force` کل تاریخچه رو با این پروژه جایگزین می‌کنه — اگه نمی‌خواید، یه ریپوی جدید بسازید)
3. تب **Actions** → اجرای "Build OneSpeed APK (Kotlin)" رو ببینید (یا دستی Run بزنید)
4. صبر کنید (~۶-۱۰ دقیقه)
5. از **Artifacts** پایین صفحه، `onespeed-apk` رو دانلود، بازش کنید، نصب کنید

APK اول با کلید موقت (debug) امضا میشه — کاملاً قابل نصب و تست واقعیه. برای امضای release واقعی، همون ۴ تا secret قبلی (`ONESPEED_KEYSTORE_BASE64` و بقیه) رو تو تنظیمات ریپو بسازید.

## نکات فنی مهم

1. `ir.onespeed.app.data.ApiService` → `GATEWAY_BASE` روی `https://devfull.sbs/app` تنظیمه.
2. اگه build خطای مربوط به `com.v2ray.ang.*` داد (مثلاً یه فایل به چیزی از `ui/` که وندور نشده اشاره می‌کرد و من ندیدمش)، دقیقاً اسم فایل و خط خطا رو بفرستید.
3. بک‌اند PHP (که قبلاً تست کردیم) بدون تغییر — اگه هنوز آپلود نکردید، طبق راهنمای قبلی انجام بدید.
